USAGE:
  Create a namespace with the steer label to enable lifecycle management:

    kubectl create namespace my-test-ns
    kubectl label namespace my-test-ns {{ .Values.namespaceSelector.key }}={{ .Values.namespaceSelector.value }}

  Or include the label in your Helm chart's namespace template:

    apiVersion: v1
    kind: Namespace
    metadata:
      name: my-test-ns
      labels:
        {{ .Values.namespaceSelector.key }}: "{{ .Values.namespaceSelector.value }}"

  View test history:

    kubectl get configmaps -n {{ include "steer.historyNamespace" . }} -l steer.io/history-for
